# 大肥鱼 · 使用说明

把 **DeepSeek Harness（DSH）桌面端**里 agent 的实时状态，投到 HoloCubic 桌搭屏上的一块
320×240 小屏幕上：它在思考、在跑工具、在等确认、报错、还是干完了，屏幕上的角色会跟着变。

- 设备地址：<http://<设备IP>>
- 应用名：**大肥鱼**（`dsh_fish`），装在 `/sd/apps/dsh_fish`
- 电脑端插件：`dsh-holocubic`，监听 `0.0.0.0:17890`

---

## 一、怎么启动

只有两件事，没有中间桥接服务。

1. **电脑上打开 DeepSeek Harness Desktop**。插件跟着 profile 的 `bundles` 自动加载，
   开始监听 `17890` 端口。
2. **设备上打开「大肥鱼」**（启动器里点图标）。手边没有设备时也可以打开
   <http://<设备IP>/dsh_fish/> 看同一个应用的管理页。

设备左上角的 `LIVE / WAIT` 变 `LIVE` 就说明连上了。

> 端口必须是 17890。被别的程序占了，插件会退到 17891，而设备只认 17890，就会一直 `WAIT`。

---

## 二、两个界面

左右倾斜设备（或按侧键）切换。

### A 页 · 角色为主（`DSH // 状态名`）

| 位置 | 内容 |
| --- | --- |
| 顶部左 | 当前状态：待命 / 思考 / 执行 / 待确认 / 完成 / 错误 / 休眠 |
| 顶部右 | `LIVE/WAIT` 连接态 + 设备时钟 |
| 中间 | 皮肤角色 160×160，会走动、会做动作 |
| 底部左 | 状态大字 + 箭头 + 项目名（DSH 的工作目录名） |
| 底部中 | 本轮对话计时、当前状态已持续多久 |
| 底部右 | `CTX xx%` 上下文占用 + 进度条 + **账户余额 `¥xx.xx`** |

### B 页 · 场景化终端（`SESSION // LIVE`）

| 位置 | 内容 |
| --- | --- |
| 顶部左 | 当前模型（如 `deepseek-flash`） |
| 顶部右 | **账户余额 `¥xx.xx`** |
| 中间上 | 终端窗：状态条 + 最近 5 条工具的滚动记录 |
| 左下 | 小号角色（96×92） |
| 右下 | 上下文百分比、进度条、已用/窗口 tokens |
| 右下两列 | **本轮 tokens / 任务总计 / 未缓存输入 / 输出 / 缓存读取 / 缓存命中率** |
| 右下最底 | **峰谷刻度条**：蓝色是谷时，黄色是峰时（工作日 9–12、14–18），小箭头指向当前时刻 |

## 三、换皮肤

打开 <http://<设备IP>/dsh_fish/>，页面上有「皮肤与动画」一块：

- **当前皮肤**：内置两套 —— `鲸鱼娘`、`蓝发少女`。选完点「应用」，屏幕上立刻换。
- **动画速度**：慢 / 标准 / 快。每套皮肤都带三档素材，换档不用重新生成。
- **隐藏**：把不要的皮肤从下拉框里去掉（正在用的那套不能隐藏）。

皮肤状态存在设备的 `/sd/apps/dsh_fish/skin.json`，重启应用、甚至重启设备都不会丢。

---

## 四、改配色

同一个管理页往下有「外观配色」：

- 背景色、面板色、描边色、主文字、次要文字、强调色、警示色、错误色 —— 八个取色器。
- 改完点「应用」，会写进 `skin.json` 的 `theme`。

> **改完要重启应用才生效。** LVGL 的样式在控件创建时就定死了，运行时改不了颜色。
> 重启方式：管理页 → 退出应用 → 重新打开「大肥鱼」。

「恢复」按钮把八个颜色还原成默认的墨绿配色。

## 五、做一套自己的皮肤

做法只有一步：把一张 **spritesheet**（每行一个动作、每列一帧的精灵表，PNG 或 WebP，
带透明通道）丢进工具。

```powershell
python tools/skin_studio.py
```

工具界面：

1. **选择精灵表** —— 自动读尺寸。
2. **填列数 / 行数** —— 工具按这个切网格，预览上会画绿色网格线，方便确认有没有切歪。
3. **右表填映射** —— 13 个事件各自填「行号 / 起始列 / 帧数」。默认值是按鲸鱼娘素材填的，
   换素材时按你的表改。帧数填 0 表示跳过该事件。
4. **填皮肤 id 和中文名** —— id 只能字母数字下划线。
5. **生成皮肤包** —— 输出到 `build/skins/<id>/`：
   - `slow/ normal/ fast/` 各一组 160×160 索引 GIF（单文件 ≤40KB，超了会自动降帧数/降色数）
   - `manifest.lua`（皮肤自描述）
   - `preview.png`（一屏看全所有动作）

13 个事件分别是：`Idle`、`UserPromptSubmit`、`PreToolUse`、`PostToolUse`、
`PermissionRequest`、`Error`、`Stop`、`SessionStart`、`SubagentStart`、`SubagentStop`、
`PreCompact`、`PostCompact`、`Sleeping`。

生成完的皮肤包，复制到 `build/dsh_fish/assets/skins/<id>/`，再跑一次
`python tools/deploy_app.py` 就同步到设备了，管理页的下拉框里会出现新皮肤。

## 六、改代码后怎么更新设备

```powershell
python tools/deploy_app.py
```

遍历 `build/dsh_fish` 里的每个文件，逐个 `PUT` 到设备 `/sd/apps/dsh_fish`（带重试，
134 个文件大约两分钟）。传完在管理页点一下重启应用即可。

> 设备把文本文件按行解析，**换行必须是 LF**。用 Python 写文件时记得
> `newline="\n"` 或事后 `bytes.replace(b"\r\n", b"\n")`，否则 `app.info` 会被判为无效、
> 应用在启动器里不出现。

## 七、常见问题

**屏幕一直 `WAIT`**

1. 确认 DSH Desktop 开着。
2. 电脑上执行 `curl http://127.0.0.1:17890/state`，有 JSON 就说明插件在跑。
3. 设备上浏览器打开 `http://<电脑内网IP>:17890/state`，打不开就是 Windows 防火墙拦了入站，
   放行 17890 端口的 TCP。
4. 检查设备 `config.lua` 里的 `host` 是不是这台电脑当前的局域网 IP（换网络会变）。

**数值不对 / 余额不显示**

插件每分钟刷新一次余额和当日账本。刚启动那几秒是 `--`，属正常。
余额需要 DSH 已登录 DeepSeek 账号。

**重启 DSH 之后设备不显示**

插件是按 profile 的 `bundles` 加载的。如果 DSH 大版本更新或换了 profile，
按 `build/plugin/install.md` 重新装一遍。

**应用图标点不开 / 启动器里没有**

用管理页的重启按钮或断电重来一次；仍然没有就重新跑 `deploy_app.py`。
